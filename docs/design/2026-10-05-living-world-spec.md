## 0. 术语表（全稿唯一定义处）

| 术语 | 定义 |
|---|---|
| **世界** | 第一公民容器：拥有自己的设定、时间、角色阵容、事件树、记忆与设置。存档单位。 |
| **事件** | 世界运转的原子发生（日常碎屑/生活节点/世界大事/角色专属/联动事件五类）。 |
| **剧情线** | 一等公民结构：挂起的事件弧（主题+关联事件集+收束条件）；有生命周期（开启/推进/收束/沉降）。 |
| **特殊时刻** | 世界运转的停止点（回信到达/中途便条/事件爆发/角色出入场四型）——值得用户在场的时刻。 |
| **走向** | 用户对世界的影响选择（导演模式的核心操作；以走向选项呈现，永不进入写信层）。 |
| **运转** | 一次完整的世界推进（§4 的七步序列）。 |
| **记忆三层** | 滚烫层（近事细节）/ 温层（摘要）/ 冷层（世界状态事实）。 |
| **唤起** | 记忆进入当前生成上下文的过程（注意力机制，非全量）。 |
| **教学贴合** | 走向选项中由教学需要生成、指向特定表达学习方向的候选。 |
| **世界包** | 官方内容的发行单位：世界设定+初始阵容+事件池+初始剧情线+教学贴合素材映射。 |

## 1. 愿景

一款本地运行的活世界笔友应用：用户与一群共同生活在一个会动的世界里的角色通信——世界在用户每次回信后运转一步，事件发生、角色各过各的日子、彼此产生联系；教学不打扰地藏在信里、走向里、与「教我」里。**用户为世界而来，把英语学会了带走。**

产品本体约束（发散期纠偏沉淀，永为边界）：秒级反馈、即时进展、绝不以「等待」惩罚用户——**感知时间 ≠ 真实时间**。

## 2. 核心体验循环

```
读信（她在等你的回信） → 写信（自由表达·学习发生处） → 寄出（在途仪式·数十秒）
→ 世界运转（事件发生·你可选看见） → 走向（导演模式给方向/沉浸模式交给随机）
→ 停在下一个特殊时刻（多数时候=她的回信到达） → 循环
```

穿插其上：教学在任意环节以三层方式介入（§6）；学习闭环的杀手锏——**你用中文写给世界的意图，被教成英文，写进真正的信里，世界回应它**。

## 3. 世界模型

### 3.1 世界的构成
设定（时代/地点/基调）· 时间（世界内日历，随运转推进）· 角色阵容（随时出入场，出入场由世界叙事化——她搬来了/他去了远方）· 事件树（编年史：信件、事件、走向、出入场皆是节点）· 记忆（§5）· 独立设置（§8）。

### 3.2 角色与关系
- 角色是世界内的演员：有自己的生活线（专属事件）、自己的记忆视角（**亲历的 vs 听闻的**——听闻可以有误差与延迟，传闻失真是天然剧情素材）、自己的通信节奏。
- **关系**：用户可预设（表亲/邻居/主顾），也可由共处事件自然演化。世界内角色彼此认识，同一事件在各自信中有各自折射。
- **互相通信**（用户开启后）：角色间有幕后往来，你偶尔听说；**传话玩法**——A 托你给 B 带句话，写一封转述信（天然的 paraphrase 学习场景）。

### 3.3 多世界
- 用户可拥有多个世界，**互不影响**；一次只「住在」一个世界里（沉浸连续性）。
- 你不在的世界静止（回合制的自然推论），但积攒着等待——召回的钩子是「有一封信在等你」，不是惩罚。

## 4. 运转引擎

### 4.1 运转的七步序列（机制定义）
1. **发条**：用户回信寄出（唯一动力源）。
2. **时间推进**：世界内日历前进若干天/周（量级随事件密度，calibratable）。
3. **事件判定**：事件池中条件成熟者发生（§4.2）；活跃剧情线推进或收束。
4. **通信编排**：世界决定哪个角色此刻写信/寄便条/静默（角色近况 × 剧情相关性 × 上次来信间隔）。
5. **停止点判定**：到达本回合的特殊时刻（多数=回信；编排停止点由事件戏剧重量决定，非机械一轮一停）。
6. **呈现渲染**：按可见性设置（§4.4）渲染运转过程与结果。
7. **等待**：世界以「她在过日子等你的信」的静默存活——暂停即牵挂。

### 4.2 事件池
- **五类事件**：日常碎屑（轻·高频）/ 生活节点（中）/ 世界大事（重·低频）/ 角色专属（绑定单角色生活线）/ 联动事件（涉及多角色——互联的载体）。
- 事件来源：世界包自带池 + 运转中动态生成 + 剧情线衍生 + **教学贴合反向生成**（§6.4）。
- 每事件有：触发条件、戏剧重量、关联角色/剧情线、后续回响钩子（**随机负责发生，连续性负责让它显得像命运**——事件必须能进入记忆并获得回响，否则不生成）。

### 4.3 走向选项（导演模式核心）
- 世界运转到「可影响点」时生成 2–4 个走向候选，来源配比：
  - 随机池加权抽样（世界基调权重：平静/多事可设）；
  - **教学贴合候选**（按占比配额注入：常规三选一、高教学频率二乃至全——占比是用户设置，§6.4）；
  - 活跃剧情线的推进方向；
  - 导演模式下用户自由输入优先（**近全权**：可基本推世界到任何方向）。
- 沉浸模式不呈走向选项，世界偏随机运转（教学贴合仍以占比进入事件生成的暗中加权）。

### 4.4 可见性（梯度）
全知（看见运转全程）/ 只看她那边 / 只看与我相关 / 全隐（只见结果——回信到达时的戏剧性惊喜）。同一引擎，渲染开关。

### 4.5 密度
运转密度（每步事件量/时间推进量）**不做先验定值**——calibratable，用户实测亲调（用户裁决）。

## 5. 记忆系统（世界如何记住）

### 5.1 三层记忆
- **滚烫层**：最近 N 个运转回合的事件，细节完整（谁/何时/原话）。
- **温层**：超龄事件压缩为一两句摘要（运转后自动降级压缩）。
- **冷层**：被反复唤起或剧情收束后的事件，沉淀为**世界状态事实**（「学徒十月离开了装订铺」）——进入世界活性事实集，**可被后续事实覆盖**（事实有生命周期）。世界现状摘要恒定地小，是每封信上下文的常驻底座。
- **遗忘**：温层事件长期无唤起（不挂任何剧情线、不被引用）则降权至「不可唤起」——数据仍在（本地全文可检索旧信），但不再进入生成上下文。**记不清无关旧事是特性，像人。**

### 5.2 注意力（唤起机制）
- **三根指针**决定唤起：当前写信的角色（她的视角记忆优先）· 活跃剧情线（线上事件加权）· 用户近信内容（语义相关）。
- 唤起沿**事件关联网**扩散一层（共现即相连——想起学徒自然带出胶水锅）。
- **剧情线**是记忆的一等挂架：线上记忆保持唤起优先；线收束，整线沉降为一条冷层事实。
- **引用强化记忆**：被提起多次的事件记忆权重升——重要的事记得牢，因为它在剧情里被反复唤起。

### 5.3 token 预算
- 世界级「记忆预算」设置（每封信上下文 token 上限）。
- **分层装配**：人设（小而恒）→ 世界现状摘要（冷层压缩，恒小）→ 活跃剧情线摘要 → 唤起事件（按相关性排序填入预算，紧则截断保头部）。
- 记忆压缩比（细节保留度）为用户旋钮；消耗可见（token 仪表，前端包在建）。

## 6. 教学系统咬合

### 6.1 三根天线
1. **纠错天线**（既有 detector 链）：用户英文信中的错误。
2. **意图天线**：用户以母语表达的任何意图（导演走向输入「岛屿发生巨大风暴」、中文信内容）→ 判定「这句话值不值得此时学它的英文」。母语意图 = 真实表达需求的完美采样。
3. **索取天线**：「教我」入口——回信中的词/句/表达、自己中文信的某句、世界事件卡的说法，一键进教学（点词查词典的自然升级：「查」→「教」）。

### 6.2 触发决策器（五砝码）
表达价值（高频/可迁移）· 距离（近发展区）· 用户旋钮（三档档位=自动层松紧）· 剧情重量（重要句值得教，学了马上用）· 当下节拍（见延迟教学）。

### 6.3 三层并存（一本预算账）
- **自动层**：底线监听一切文本，达阈值触发。
- **潜入层**：不出手，在回信中轻标记「值得学」的表达——可见但不打扰的缓冲带。
- **主动层**：「教我」。主动密集时自动层识趣降频——教学预算全局一本账。

### 6.4 教学贴合与主从解（用户裁决）
教学为世界让路为常态；反向生成走**可见的贴合选项**：走向候选中按用户设置的占比注入教学贴合项（贴合=该走向将产生需要特定表达域的剧情——「教堂义卖的邀请函」贴合 formal 语域）。**贴合标注与否本身是设置项**（标注=知情选择；不标=学习藏在兴趣里）。

### 6.5 延迟教学
剧情高潮处只开潜入层；高潮过后（下封信间隙/回信收起时）教学跟进。保情绪增强记忆的红利，不打断沉浸。

### 6.6 学习闭环（杀手锏）
中文意图 → 教学教英文 → 学到的英文写进真正的信寄出 → 世界回应它。学习获得即时世界性回报。

## 7. 信息架构

### 7.1 IA 翻转（用户裁决）
**世界是第一公民**：先有世界，再有角色；角色共享一个事件树；信件是世界运转的输出。现行「角色→会话」结构重定位为世界内视图。

### 7.2 新手路径（总控设计）
首开三步内进入预制世界 **Berrymoor**——Nell 的第一封信已到，你的第一个动作就是回信（核心循环零门槛启动）。教学在头三封信内以潜入层首次现身；第一个世界事件在首周内到来，世界感建立。**角色分批入场即新手节奏**：首发 Nell，Theo/Priya/Evelyn 在随后数周陆续「搬来」（世界包的入场编排）。高级能力（自建世界/导演模式/多世界）不隐藏、不打扰，稳定使用后自然揭示。

### 7.3 世界创建（总控设计，三档）
1. **官方世界直接用**（默认）。
2. **模板分叉**：复制官方世界并个性化（改设定/换阵容/调基调）——「平行世界」。
3. **从零自建**（高级）：写世界设定 → 选/建角色 → 定基调与事件倾向。

### 7.4 多世界 UI（总控设计）
- **案头 = 当前世界的收件箱**（沉浸连续性，一次住一个世界）。
- **世界架**：世界切换面（书架/抽屉隐喻，每世界一格，有待读信角标；别的世界静上但等待可见）。
- 世界指示器：当前世界名 + 世界内时间/天气的静默暗示。

### 7.5 角色出入场
随时加入/删除角色；**出入场由世界叙事化**（入场事件/退场事件自动生成——她搬来了/他去了远方）。删除与叙事留痕并存（本地应用，无隐私语义——用户裁决）；叙事上可保留其存在过的痕迹。

## 8. 设置面全景

**世界级**（每世界独立）：模式（导演/沉浸）· 可见性（四档梯度）· 教学贴合占比 · 贴合标注开关 · 世界基调（平静↔多事）· 记忆预算与压缩比 ·（实测后开放）运转密度。
**全局**：教学三档与频率旋钮（现役面）·「教我」入口显隐 · 主题/排印等。
→ 落位：现役设置页分组 IA 的世界组扩展（主线-1 已建框架）。

## 9. 官方内容形态：世界包

**Berrymoor 首包** = 世界设定（港口小镇·慢基调）+ 初始阵容（Nell 首发，三角色编排入场）+ 事件池（日常/季度/节点三层）+ 初始剧情线 1–2 条 + **教学贴合素材映射**（世界事件 → 表达需求域的映射表，供贴合选项生成）。
后续包方向：四个官方角色的背景即四个世界胚子（Manchester 职场世界 / Wellsby 书信小镇……）。**内容生产单位从角色包升格为世界包。**

## 10. 与现役系统的关系（衔接锚，非工程方案）

- **吸收/升级**：角色卡→世界内演员；lore 事实→冷层世界状态（生命周期语义已合）；episode/relationship→角色视角记忆底料；教学卡/词卡→天线输出面；设置页→世界设置扩展；token 计量（在建）→记忆预算仪表。
- **真新域（量级诚实）**：世界运转引擎（事件池/七步编排/剧情线）、记忆系统（三层+唤起+预算）、意图天线判定器、走向选项生成器、世界包格式。**这是产品级重构，多刀多相位**——具体刀序是 M0 工程对齐文档的事。

## 11. 产品里程碑（能力台阶，非工程刀序）

- **M0 收敛与工程对齐**：本稿审裁定稿 → 对工程现状出建设方案（域划分/刀序/依赖）。
- **M1 最小活世界**：单世界·回合运转·Nell 通信节奏·滚烫层记忆——「她活起来了」。
- **M2 剧情与教学咬合**：事件池·走向选项·三天线·贴合占比——「学习藏进了世界」。
- **M3 多世界与编排**：创建三档·世界架·出入场叙事化——「你是造物者」。
- **M4 记忆深化与打磨**：三层全自动·唤起·预算·叙事外衣（画龙点睛阶段）——「世界有了自己的生命」。
