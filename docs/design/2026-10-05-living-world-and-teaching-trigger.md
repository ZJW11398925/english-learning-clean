## 1. 原始问题（用户主创）

对话缺少将用户带入流程的能力：**对面的时间不流动**（笔友被冻结，只在收信时活一下）；**用户始终是发起者**且无特殊反馈——持续使用的动力不足。构想方向：给对话加上剧情——对面的世界会变化、笔友度过自己的生活、**不同角色之间产生关系与互动**。

## 2. 回合制世界运转模型（用户主创，总控结构化）

```
用户回信 ──▶ 世界运转一步 ──▶ 运行至「特殊时刻」──▶ 停下等用户
   ▲              （过程与事件可选可见/不可见）            │
   └──────────────────────────────────────────────────────┘
```

- **驱动方式**（用户定）：偏随机 / 由用户引导 / 混合；用户可自主设置。
- **酒馆应用范式移植**（用户观察）：模型在每轮结尾给出几个走向选项 → 用户决定大方向 → 下一步事件发生。用户享受**控制、创造、过程中的随机性**。
- **总控修正（关键分层）**：选项属于**世界层，永不进入写信层**。写信保持自由表达（学习发生之处，不可被点选稀释）；信寄出后世界运转时才出现走向引导。**写信时你是笔友，选走向时你是导演，看事件时你是观众**——三层身份切换是此类产品粘性的深层结构。
- **特殊时刻谱系**（总控添）：回信到达为主锚点（常态）；偶发**爆发性事件**停点（暴风雪之夜——比回信更有「必须说话」的重量）；最轻形态**中间便条**（两行，「等不及想告诉你」）。停点由事件戏剧重量决定，非机械一轮一停。
- **等待的姿态**（总控添）：停下不是冻结——世界以「她在过日子等你的信」的静默暗示存活。暂停即牵挂。
- **随机性的品质**（总控添）：随机事件须进入记忆并获得后续回响，否则感知为「系统拼贴」而非「世界有生命」。**随机负责发生，连续性负责让它显得像命运。**
- **缺席语义**（总控添，源自应用本体约束）：用户不来的日子世界不走（不惩罚）；可温和积攒一封「你不在的这段时间」的信作召回钩子——离线的产出感优于在线的等待感（idle 机制最被验证的一手）。

## 3. 可见性开关：两台戏共用一个引擎（用户主创「可选看见」，总控展开）

同一世界运转，开关一拨两种产品：
- **看见**＝上帝/导演视角：世界运转可观，事件如剧集展开，可旁观可干预。
- **不看见**＝戏剧性惊喜：信息差本身即叙事张力（「学徒走了？我怎么不知道！」）。
- 可见性是**梯度**而非二值（只看与我相关的 / 只看她那边的 / 全知）。

## 4. 教学触发模型（用户主创，总控深化为「三根天线」）

**用户的原始表述**：教学触发取决于用户输入了什么——例如用户在导演台用中文写「Nell 所在的岛屿发生了巨大的风暴」，教学系统应处理「这句话值不值得让用户此时学习其英语表达」，依据学习目标、教学频率等做出决定；角色回信、世界事件亦能触发；且可留「教我」入口供用户自主进入。

**总控深化——三根天线**：
1. **纠错天线**（既有）：检测用户英文输出错误（现役 detector 链）。
2. **意图天线**（新，设计核心跃迁）：用户用母语表达的导演意图 = 真实表达需求的完美采样。闭环杀手锏：**中文意图 → 教学教「风暴」的英文 → 学到的英文写进真正的信寄出 → 她的回信回应这个英文**——学习获得即时世界性回报。
3. **索取天线**：「教我」入口——长按回信中的习语/自己中文信的某句/世界事件卡的说法，一键进教学。补自动判断的永久盲区：**只有用户自己知道此刻想学**。

**触发决策器的五块砝码**（总控数出）：表达价值（高频/可迁移）、距离（近发展区）、用户旋钮（学习目标/教学频率——三档档位即自动层松紧）、剧情重量（重要句值得教，学了马上用）、当下节拍（见下）。

**三层并存**（总控）：自动层（底线监听）＋**潜入层**（不触发完整教学、回信中轻标记「值得学」的表达——可见但不打扰的缓冲带）＋主动层（教我）。三层流量连着算一本教学预算账（主动密集则自动识趣降频）。

**延迟教学**（总控解法，针对高潮悖论）：情绪峰值处表达价值最高、打扰代价也最高——高潮时只开潜入层，高潮过后（下封信间隙/回信收起时）教学再跟进。保留情绪增强记忆的红利，不打断沉浸。

## 5. 未决设计题（开放，待后续发散轮）

- **运转密度**：世界每步发生多少事件是对「世界感」与「过载」的分界。
- **控制边界**：导演模式可推世界到任何方向吗？随机层需保留「不可否决的最小事件流量」（世界不完全听你的=它活着）。
- **教学的叙事外衣**：批注卡延续 vs 彻底剧情化（她在信纸页边教你——她注意到你没听懂她的用法）。
- **教学与剧情的主从线**：教学为世界让路（延迟/潜入/旋钮都是让路姿态）——要不要反向时刻？剧情事件由教学需要反向生成（弱项 formal ⇒ 世界「恰好」来一封需要正式回信的邀请函）。**世界为学习让路还是学习为世界让路，这条线是产品最深的一笔。**
- **角色互联深度**：互提彩蛋级 vs 同事件多视角剧情级 vs 他们互相通信（用户原始构想含此项）。
