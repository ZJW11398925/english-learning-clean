## 域一：认知模型（三源认知）——「数据层全知，认知层分视角」

**原则**（承 spec §3.2「亲历的 vs 听闻的，听闻可以有误差与延迟」）：「世界」不是认知主体——它是事件编年史（append-only 全知）+ 状态投影（现在为真的事实集）。**认知是每个角色各自的投影视角**：

| 认知源 | 内容 | 形态 |
|---|---|---|
| **公共层** | 小镇公共知识：天气、季节、公认大事 | 所在角色可得 |
| **亲历层** | 该角色在场/参与的事件 | 细节完整 |
| **听闻层** | 传闻到达 ta 的事件 | 摘要级；**可有延迟与失真**（失真是剧情素材，非缺陷） |

**工程形态**：
1. 事件加 `participants` 标记（谁在场/谁参与）——编年史行的一列；
2. 角色认知视图 = 公共层 + 亲历层（participants 含我）+ 听闻层（v1 简化为「同镇公共事件」，**传闻失真层后置**——先立结构，失真质量靠 dogfood 校准再加）；
3. wr-12 的「近 5 条全量窗口」升级为按角色过滤的认知视图（Nell 的视图与 Silas 的视图不同）；
4. 角色间交流/角色反应 = 事件（入编年史，带 participants）——不另建通道；
5. 关系 = 状态投影的动态事实（关系演化事件 → 「现在为真」的关系事实，supersede 语义）——叙事者读投影，不读全史。

**裁断点**：①传闻失真层是否 v1 后置（我建议后置）；②participants 最小集（在场者 vs 参与者是否分两档——我建议 v1 一档）。

## 域二：剧情线（小说的「情节」层）——弧、伏笔、回收

**原则**（承 spec 术语表「剧情线 = 一等公民结构：挂起的事件弧〔主题+关联事件集+收束条件〕，有生命周期」）：

```
剧情线 storyline：
  theme        一句弧主题（"渡船航线要停了"）
  opened_by    开启事件
  linked       关联事件集（编年史 id 引用）
  hooks        未兑现的回响钩子（伏笔队列——spec §4.3 每事件的后续回响）
  status       活跃 / 收束 / 沉降（收束后整线沉降为一条冷记忆要点，spec §5.4）
  resolve_at   收束条件（叙事性描述，由叙事者判定）
```

**运转咬合**：
- 叙事者每步读**活跃剧情线摘要**（不是全史）——弧感由此来：埋线（hooks 入队）、推进（步叙述挂线）、收束（条件满足时叙事者宣告，线沉降）；
- 走向候选沿活跃线推进 vs 开新线（spec §4.4 来源配比的「剧情线推进方向」腿）——候选有弧感的来源；
- **走向选择直接干预剧情线**（导演选向 = 给线一个方向事件）——导演模式的实质抓手；
- 伏笔回收 = hooks 队列的兑现——叙事者的长程记忆靠「线」不靠「加窗口」。

**裁断点**：①v1 是否只做「单世界 ≤3 条活跃线 + 手工开启」（世界包初始线 + 叙事者自然开新线后置）；②线的数据落点（新表 or 编年史特殊 kind——我建议新表，迁移 0027）。

## 域三：角色声音库（语言去 AI 味的核心杠杆）——「模仿具体语样远胜遵循抽象描述」

**原则**：模型遵循「她说话简洁」远不如模仿**她自己写过的三段话**。借鉴 **SillyTavern 角色卡 v3**（example_dialogue 区是成熟格式）：

```
声音库 voice（每角色）：
  speech_habits   说话习惯（句长/语气/节奏——三句以内描述）
  never_says      不说的词（禁忌词表——"她从不用感叹号"）
  quirks          口头禅与习惯动作（≤3 个）
  samples         亲笔语样 3-5 段（信件片段级范文——声音的真源）
  register        语域锚（小镇口语/书面/混杂 + 词汇表倾向）
```

**运转咬合**：角色声音库入 **persona 回信 prompt**（她的信像她）与**叙事者 prompt 的角色出场区**（叙事中她说话像她）；语样由世界包提供（Berrymoor 先给 Nell + 五居民补齐——**素材深化刀**）。

**裁断点**：语样语言（英文为源 + 中文对照？我们的 narration 双语——建议语样双语各三段）。

## 域四：叙事工艺指引（护栏级注入）——行文规范的核心抽提

**借鉴源**：`小说ai行文规范`（36 条反 AI 味病征 + 34 红线 + 零频套语库 + 三铁律）——**成品级资产，抽核心入叙事者节律指引**。规范全量留在参考资料位（不塞 prompt——防膨胀），注入的是抽提的护栏：

**叙事者三铁律**（规范第三节，语言无关可迁移）：
1. **动作不许干打**——每个动作句在「做了什么」之外至少两项（修饰/状态/心理/余波）；
2. **台词分诊**——短台词是性格还是偷懒？是性格就留，是偷懒就补姿态与余波；
3. **详略主次**——句句都修饰=没有轻重；只在本段重音处修饰，其余白描。

**反 AI 味核心负例**（第十节抽提，prompt 注入 ≤10 条最高频）：空泛拔高、套话收尾升华、程度副词通胀、比喻过载（单段≤1）、情绪词直给（写身体反应）、无功能景物、段长等长、流水账有顺序没主次。

**叙述者人格**（规范第二节「叙事总契约」）：**叙述者有性格、可轻吐槽、可预知，永远不自稱「我」**——比现役 "You are the narrator of a small fictional world" 丰富一个量级的叙述者设计；视角纪律（镜头挂主角但可跳，跳转打信号）。

**语言适配**：规范源自中文网文语料——**工艺原则语言无关直接迁移**；例句与套语库按目标语言适配（英文叙事另有英文套语表——dogfood 信号补充）。双语各维护一份套语黑名单。

**注入位置与克制**：护栏 ≤15 行进叙事者节律段；全量规范作为**生成后自检参考**（质量回路：抽样外评/dogfood 对照清单查，不每步自评——成本纪律）。

**裁断点**：①负例注入量（≤10 条最高频 vs 全 36 条——我建议 ≤10）；②英文套语表 v1 是否先空（dogfood 信号补——我建议先空）。
