### 2. 「信感」解构（12 条，从底到顶）

1. **纸是一组色号，不是一个白色**：≥3-4 个纸色层级，差值走暖度与明度微差（ΔL 3-6%），纯白只留给最上面一张【实测 Miranda/TCI/指南】
2. **墨是着色黑不是 #000**：3-8% 色相偏移；标题色 ≠ 正文色【实测 6 站】
3. **厚度 = 带色偏移阴影 + 发丝描边**：阴影方向不一致（人手摆放感）；阴影色 = 墨色降透明度；描边发丝级且暖色【实测】
4. **纤维纹理：真拍贴图且极致克制**：≤3-5% 或 multiply 只叠纸张层，**绝不叠文字容器**【实测 + Awwwards 警告】
5. **印刷版心**：行宽上限（中文 22-28 字/行）；页边距 ≥2 倍行高；**任何时刻 ≥40% 是空纸**
6. **字体三人组**：衬线发声 / 无衬线做事 / 等宽当标尺（打字机 = 元信息角色）【实测 7 站全此结构】
7. **微标签工艺**：小字号 + 0.05-0.08em 字距 + 暖灰 + 全大写（西文）；**不用彩色徽章/胶囊**
8. **手写体只出现在签名位**（落款/日期/批注/边注）——正文手写体 = 从印刷品跌到文创小店【实测全站无一例外】
9. **痕迹与残留**：印章/邮戳/贴纸/纸夹/折痕，带随机性（±0.5-2°、位置偏移）且低对比，**每屏 ≤1 处且必须对应真实事件**
10. **机制物化**：等待=在途/未拆封；完成=盖戳/归档；批改=页边批注；累积=成册合订——**真信与假装信的分水岭**【Slowly 反证】
11. **视角是纸上的物件**：旋转/叠放/抽取（位移+阴影同步）；**禁泛光/模糊/弹性回弹**（UI 语汇非纸语汇）
12. **动效物理**：短、轻、有摩擦（200-400ms ease-out，位移与阴影同步）；**纸不发光**

### 3. 对我们产品的 9 条建议（按消除「白板感」排序）

1. **纸做成色号体系，取消纯白底**（高）——4 个纸色 token（如 `#F5F1E8/#FBF8F2/#EFE7D9/#E4DACB`），每层配发丝描边 + 偏移阴影
2. **墨色与阴影全部着色黑同源**（高）——正文墨 `#211D18` 量级、标题更深更暖、元信息暖灰；阴影 = 墨色降透明度且方向不统一
3. **三体例写死中西文配对，正文禁手写体**（高）——衬线=教学叙述（西 Source Serif/Spectral/Crimson Pro + 中文书宋）；无衬线=控件；等宽=时间/编号；手写只配落款/批注
4. **版心重排：窄行宽 + 眉批/边注 + 留白配额**（高）——元信息排成印刷品眉批（小字号+字距+发丝线），不是侧边栏卡片
5. **微标签工艺替代彩色徽章**（高）——状态差异第一次用文字表达，第二次才用颜色
6. **真纸纹理只给纸不给字**（中）——multiply 3-5%，文字容器永远干净；中文小字号+纹理=笔画糊，需真机验证
7. **信感投资到机制而非皮肤：在途、盖戳、合订、批注**（高·需产品配合）——**最重要发现**：机制不改皮肤无效
8. **纸的物理动效：短促有摩擦；禁发光/回弹/模糊**（中）——200-400ms ease-out；prefers-reduced-motion 瞬切
9. **旋转/撕边/无留白报纸构图只做点缀**（低）——中文正文旋转 = 可读性可访问性双输；只保留小面积邮戳/印章旋转

### 4. 负面清单（噱头）

手写体正文；满屏纹理/做旧泛黄/咖啡渍；蜡封动画/信封拆封转场/撕裂转场（一次性惊喜变日常负担）；牛皮纸+手写便利贴+麻绳（文创店语汇）；纯白卡片+大圆角+彩色徽章（**正是被判白板的现状**）；用纹理冒充信感。

### 5. 缺口

letter-writing app 的 App 级 UI 细节（Mobbin/Dribbble/Behance 全被拦）——Slowly 真实信纸编辑界面未取得；Awwwards 合集分页未采完；Kinfolk 现站运行时字体未提取。

**一句话结论**：信感的 90% 可照抄工艺（纸色号/着色墨/偏移阴影/发丝线/三体例/微标签/窄行宽/低透明真纹理/痕迹随机化），真正的 10%——**在途、盖戳、批注、合订**——只能从产品机制里长出来；Slowly 官网毫无纸感却依然像信，是最好反证。

## 调研B：学习产品信息架构

### 一、15+ 产品 IA 模式卡片

- **Duolingo**：线性学习路径为唯一主线 + streak 常显；练习收独立 Practice 标签（Mistakes/Words/Speak/Listen 各自按需）；**成就从「埋藏」到「陈列」的官方自认失败往返**——纪念物藏太深会失去意义
- **WaniKani**：仪表盘 = 可增删拖拽 widget（Lessons/Reviews/Level Progress/Next 24h/Recent Mistakes）；SRS 五组词（Apprentice→Burned）；社区抱怨 widget 浪费空间——「密度必须可调」活教材
- **Bunpro**（最该抄）：行动按钮最大（Review/Learn + 下拉切分）；统计退到 Profile 后——学习面/记录面分工干净
- **Anki**：默认面只有牌组列表（开即复习）；Stats 独立窗口；Browse = 搜索型深档——**历史不靠浏览靠检索**
- **LingQ**：统计按「活动」组织；**把 Known Words 从下拉拿掉——「活动的副产品而非活动本身」**；官方自认老用户不便但方向不改
- **Quizlet**：全部历史缩成一句 Recent activity
- **FluentU**（反面）：完成态反馈出名地乱
- **Memrise**：分数常显、词表进抽屉——「计数一个就够，明细按需」
- **Day One**：Today 视图 + On This Day 触发式回忆——**历史是触发式回忆不是可滚动坟场**
- **Bear**：标签树 + 搜索 = 无限历史不乱；代价是用户维护词表
- **Notion Dashboard**：官方判据原文 **"Start with high-level insights. Use widgets as entry points to explore the underlying data when needed."**；避免 "large, unfiltered table widgets"
- **Streaks**：日常面只回答「今天做没做」
- **Strava Trophy Case**：只露最近 4 枚 + View More——**「最近几个+更多」是收藏档标准形态**
- **Todoist Karma**：游戏化藏头像后，自取制
- **Apple Fitness**：进度 = 一个可穿戴目标图形
- **Khan Academy**：词级熟练度（Attempted→Familiar→Proficient→Mastered）+ 单条进度（官方为避免双进度条而删条）

### 二、方法论判据

1. 渐进披露（NN/g）：**层级深度上限 2 层**
2. 信息气味（NN/g）：**jargon/branded terms 造成无可用线索**（→ 反对雅名双关）
3. Shneiderman：overview first, zoom and filter, details on demand
4. Dashboard 反模式（Stephen Few）：过一屏/无上下文/过细精度/度量不当/图表错配/无意义花样；NN/g：dashboard 应「快速消费、最少交互」
5. **学生侧仪表盘研究（Valle 2021, PMC8153529）：预测型 dashboard 对初始动机低者显著负作用（-0.86）**——不向学员展示排名/百分位/对比
6. 行动优先（SoL 2020）：要推荐/计划/目标编辑/直达内容，不要「数据解码」
7. 开放学习者模型（OLM）：开放什么/如何呈现/谁控制三维度先定
8. 空态（NN/g）：**内容未加载就显示「无记录」= particularly harmful**（异步教学时刻直接命中）
9. 渐进摘要（Forte）：**历史记录的正确命运是被压缩，不是被展示**
10. Hick's Law：一级入口硬上限
11. Wrapped 模式：**数据不够就不解锁**（Spotify 门槛 30 首）——解决密态难看空态尴尬

### 三、「常显/按需/收藏档」三分判据

- **常显**（≤3 块、单屏、不滚动、每块落成动词按钮）：使用频率 ≥ 每日；直接驱动动作；一眼可判；时间敏感；缺失造成不可逆损失
- **按需**（入口可见、内容点击后现、两层封顶）：每周 1 次以上非每日；只在决策/核对时有用；需上下文才能理解；**内容随时间线性增长必须折叠**
- **收藏档**（默认无入口或深入口；可搜索/可导出；每 3-12 个月由里程碑/周年主动揭示）：< 每月 1 次；只有回顾/取证/导出价值；逐条阅读无意义；**展示会引发焦虑/攀比/误读**

记忆句：**常显 = 今天要用；按需 = 做决定时要查；收藏档 = 值得被重新讲一次故事的**。

### 四、重构提案（三套）

**提案 A「今日一屏」**（最激进）：整屏只有今日状态 + 主按钮 + 环；成长/计划/档案全次级。代价：「系统记得我」的感觉蒸发。
**提案 B「今日 + 一行成长」（推荐）**：
- 默认层 ≤3 块：①今日行动（到期 N 项 + 进行中教学 + 一个按钮；N=0 时「今天不用复习，要不要聊一句？」）②成长摘要固定 3 条**词级结论**（「你现在能做到：…」——不是列表是结论）③一个环
- 次级层：点成长条目 → 抽屉（一句结论 + 「依据」近 N 次观察摘要 + 原件折叠最后 + 「为什么」）；排程/目标清单进「计划」按需页
- 深档：「档案」= 搜索优先聚合时间线（按周/月折叠成一行一句）+ 主题过滤；每季/年「回顾封装」（数据不足不解锁）
- 空态：成长位换 pull revelation 卡；**教学时刻生成中显示明确加载态**
- 密态：成长恒 3 条（选出来不是全放出来）；档案 30 天/年折叠
- 导航：2+1（今日/成长 + 右上档案入口）
**提案 C「时间线一元制」**（不推荐，与「大量信息不必看见」直接冲突，但其搜索/折叠形态被 B 吸收）

推荐理由：与现有数据模型同构（能力证据/观察/时刻——聚合后常显一条、原件归档，**不砍功能只改分层**）；同时满足「不打扰」和「系统确实记得我」；Bunpro/WaniKani/Notion/Strava/Day One 全是现成组成件。

**命名建议**：学案→「今天」；柜抽→拆「成长」（按需·意义面）+「档案」（深档·事实面）；全站词表统一（今天/计划/成长/档案/回顾）——**治「毫无章法」的第一味药**。

### 五、「从用户眼前移走」清单

| 现状信息 | 处置 | 理由 |
|---|---|---|
| 目标清单（列表） | 降级+压缩（默认一句「方向」，全量进计划页） | >3 条即表格坟场；低频决策物 |
| 复习计划全量排程 | 降级（默认只留今天到期 N + 按钮） | 时间敏感的是今天不是下周 |
| 教学时刻列表 | 拆两半：进行中留常显、历史归档聚合 | 历史聚合成「本周 3 次教学，主题 X/Y」才有信息量 |
| 观察流水 | **整体移走（归档）**，以一句话摘要+证据抽屉呈现 | 系统内部材料非用户内容；逐条展示=天书 |
| 能力证据原件 | 降级+聚合（默认 3 条词级结论；重大进步里程碑揭示） | 结论句才是自我认知 |
| why_not 原委 | **移走**（用户面 0 展示，最多一句「今晚不打扰你」） | 内部决策理由 = 噪音+焦虑源 |
| 各类计数 | 合并（最多 1 环） | 计数是 byproduct |
| 内部数值（confidence/priority/readiness 档位） | **永不面向用户** | 词级表达替代 |
| 排名/百分位/对比 | **不做** | Valle：伤士气 |

**保留常显对照**：今日到期数、进行中教学、开始按钮、一句状态、≤1 环、成长 3 条。

### 六、落地顺序

①改名+词表统一（零风险）→②默认层三块化→③档案搜索+折叠+回顾封装。风险：常显块超 3 个立刻回归坟场；成长必须词级可解释不评分；空态区分「没有」与「正在生成」。

## 调研C：动效与手感

### 0. 三条手感原则（比动画更重要）

1. **100ms 内必须有可见反馈**（NN/g 感知即时阈值）——手感差的主因是按下 150ms 没变化
2. **越频繁的动效越短越弱**（NN/g + Apple HIG「高频交互通常应避免动效」）
3. **进入 ease-out、退出 ease-in、位移标准曲线**（Carbon 三组）

此外手感的一半不在动画：cursor 语义正确、命中区 ≥44px、:focus-visible 等价反馈、hover 用 `@media (hover:hover)` 包裹、提交后乐观反馈。

### 1. 动效词汇表（20 时刻，信件隐喻）

**A 送达组**：①信纸落桌（视图首渲 6-10px 上浮+淡入 320ms emphasized-decelerate）②短笺递出（DOM 插入 10px+淡入 240ms standard @starting-style）③墨迹显字（标题 clip-path 揭开、每行错 60ms、400-600ms）④逐行落墨（列表 stagger 每项 160ms 延迟 i×40ms **总封顶 320ms**）⑤拆封（页签切换 View Transitions 交叉淡化 200ms）
**B 书写组**：⑥笔尖落下（聚焦下缘墨线 scaleX 200ms）⑦打字机上字（**仅限状态行**「正在落墨…」逐字 20-35ms；**长文与每轮回复禁用**）⑧墨滴扩散（按压点径向显影 ≤12% 幅度 320ms）⑨划线（hover 下划线自左画出 160ms）
**C 启封压印组**：⑩封蜡压印（关键确认 240-320ms 轻超调 `cubic-bezier(.34,1.2,.64,1)`）⑪邮戳盖下（发送 scale .96→1 + 阴影收束 120ms）⑫蜡点未读（**单次** 400ms 脉冲绝不循环）
**D 柜格组**：⑬柜抽开合（进 280ms decelerate/出 200ms accelerate）⑭折信展开（scaleY .98→1 + 内容延后 80ms 280ms）⑮换格（FLIP 240ms 只动 transform）
**E 回执组**：⑯回执条（**优先 inline 就地变色其次 toast**；进 200 出 160 停 3-5s）⑰抹去（淡出+轻微缩小，**不飞走不爆炸**）⑱墨干落定（active 回 idle 禁瞬跳 200ms）
**F 环境组**：⑲纸纹微光（≥20s 超低对比、**默认关闭**、避开 ~0.2Hz）⑳翻页暗示（滚动分节 1-2° 倾斜一次性 ≤240ms）

节奏：同屏最多 1 expressive + 1 standard；大动效一天一次（信不喧哗）。

### 2. 时长缓动档位表

| 档 | 时长 | 进入 | 退出 | 依据 |
|---|---|---|---|---|
| micro | 80-120ms（推荐100） | — | ease-out | Carbon fast-01/02；NN/g |
| standard | 160-280ms（推荐200） | `cubic-bezier(.05,.7,.1,1)` | `cubic-bezier(.3,0,1,1)` | M3 short4/Carbon moderate-02 |
| expressive | 300-500ms（推荐320-400） | 同上 | `cubic-bezier(.3,0,.8,.15)` | M3/NN/g 上限 500 |
| ambient | 700-1000ms | linear/standard | — | M3 extra-long（仅无输入装饰） |

**上界纪律**：500ms 起「像在拖拽」；进入比退出略长。可直接抄的曲线：standard `(.2,0,0,1)`、decelerate `(0,0,0,1)`、emphasized-decelerate `(.05,.7,.1,1)`、emphasized-accelerate `(.3,0,.8,.15)`、legacy `(.4,0,.2,1)`、轻超调 `(.34,1.2,.64,1)`（仅落桌/盖印）。**M3 的坑**：`emphasized` 在 CSS 实际 = standard 同值，别指望名字有魔法。

### 3. 实现路径（vanilla 无构建链）

- **第0步 tokens+纪律**（半天，收益最大）：`--dur-micro/std/exp/amb` + `--ease-enter/exit/move/legacy` + Material state layer 实测值（hover .08/focus .12/press .12）+ stagger（step 40ms cap 320ms）；reduced-motion 用 1ms 技巧（保 animationend）；**JS/WAAPI 必须自己监听 matchMedia 停动画**
- **第1步纯 CSS 手感层**（覆盖 80% 抱怨）：状态层伪元素、hover translateY(-1px)/active scale(.99)（触屏 @media 包裹）、stagger `--i` + `animation-fill-mode:backwards`（防先亮一下）、**`@starting-style`**（动态插入元素/DOM 首渲/display 切换——Baseline 2024-08，缺失=直接出现天然渐进增强）
- **第2步 IntersectionObserver**（15 行，入场编排主力；回调只加 class）
- **第3步 View Transitions API**（`document.startViewTransition ? ... : fn()`；**唯一性硬约束**同名 reject 整体跳过；**Firefox 144 才支持必须留 else 分支**）
- **第4步 WAAPI/FLIP**（列表换位；预计算 ~100ms 窗口；只动 transform/opacity）；弹簧：多数非弹跳、颜色透明度不用弹簧、CSS `linear()` 可零 JS 逼近
- **第5步可选** `interpolate-size: allow-keywords`（Experimental Chrome 129+，降级直接展开）

**铁律**：不支持 + reduced-motion 两种情况下界面必须功能完整信息不丢。

### 4. 反模式（14 条）

整屏 3D 翻页；视差（前庭风险首位）；常驻循环/持续振荡（**~0.2Hz 是 visionOS 点名不适源**）；撒纸屑礼花；打字机用于长文/每轮回复；全局弹跳 overshoot；常规 >400-500ms；动画阻塞输入；**动画是唯一信息载体**；无封顶串行 stagger；动画 width/height/top/left/box-shadow；无限 shimmer/<1s 闪骨架；音效震动光标滥用；hover 才暴露关键操作。

### 来源

Material 3 tokens（规范+material-web 实测）、Apple HIG、Carbon、NN/g（duration/microinteractions/skeleton）、web.dev（reduced-motion）、WCAG 2.3.3、MDN（VT/@starting-style/interpolate-size/linear()/IO + compat）、Aerotwist FLIP、Comeau 弹簧。**「Natasha Postolovski 文章」多引擎无果，已用 Saffer 四段式替代**。

## 调研D：游戏与叙事界面质感

### 一、15 案例卡片（要点）

1. **Cultist Simulator**：桌子即界面，卡拖进动词格；RPS「moving cards feels satisfyingly ritualistic」；不设教程最有争议（我们不要）。→ 抽象动作具象为「可投放位置」；知识在物上逐步显形
2. **Inscryption**：单一场景可信度（一张小屋牌桌）；伤害=牙齿落天平；牌会「乞求」。→ **状态实物化**（核心进度是桌上的一件物）；**视角纪律**（界面只在桌子能看见的范围内）
3. **Return of the Obra Dinn**：1-bit 抖色；笔记本即推理容器；**推断正确被 etch 永久刻进书页**。→ 「被确认的内容才配永久化」；报告书式排版（编号/字段/小图）胜过聊天气泡
4. **Papers, Please**：桌面工作台；**clunky 界面是刻意设计**（HyperCard 灵感，控制信息可见度）。→ 印章=判决（不可撤销的盖章动作）；保留一点手工笨拙（但配快捷键与撤销）
5. **80 Days**：75 万字单局见 2%；**地图上选路线不是菜单**；少而准的插图。→ 学习路径做成可点的路线图；一信一插图胜过满屏图标
6. **Florence**：交互即情绪；**越熟悉对话谜题越容易**。→ 语言难度与关系亲近度挂钩；轻交互替代评价文案
7. **Lifeline**：短信体；真实时间等待「[Taylor is busy]」；通关解锁 Fast Mode。→ 延迟成为叙事材料（「对方正在写」）但必须可跳过；二选一回复压决策成本
8. **Sunless Sea/Skies**：35 万字 storylet；**船开得慢+音乐=紧张感**。→ 文本有档案层级（正文/脚注/边注/可展开旧信）；**用节奏而非动画数量制造氛围**
9. **Where the Water Tastes Like Wine**：故事作为物被携带与转述。→ **转述即复习**
10. **Tabletop Simulator**：物理沙盒「pick up, rotate, shake, throw」。→ 拖拽给一点惯性/回弹/吸附位；只给当前该动的物物理性
11. **Dorfromantik**：handpainted boardgame feel、quiet peaceful world；**目标写在世界里**（风车想邻 6 块麦田）。→ 学习目标以「事物的请求」出现比 KPI 面板温和
12. **Wingspan**：170 张手绘鸟类卡「field guide-caliber」。→ 卡片走图鉴页版式（小图+字段+短注）；**空卡才是白板感根源**
13. **Kind Words**：房间是唯一视角；请求=一行字的卡；纸飞机飞过屏幕；**贴纸会变成房间里的 3D 摆件**；官方意图「一个让人安定的地方」。→ 陌生人一句话请求做低压力写作入口；**长期成就用陈列表达不是数值条**
14. **Her Story**：封存的台式机 + 关键词检索影像。→ **检索本身可以有质感**——信库里查一个词命中若干封信；用过时容器（档案柜/旧系统）表达被保存的学习史
15. **Things 3**：反拟物一极——官方自述「更像一张干净挺括的纸」「**每个动画都有目的**」「unfolding animations keep your place」。→ **纸不必被贴出来：干净确定的版式本身就有纸感**；动效天职是「保持你的位置」

### 二、「物感」手法清单（16 条）

表面材质（feTurbulence 噪点低到「看得出说不出」）；边缘不规则（只给信与批注，容器端正）；层级深度（**全局统一光源、阴影 ≤2 级**）；抬升-抽出-展开动效（150-350ms，一次一件）；手感阻尼与吸附位；压印/凹刻（text-shadow 单像素偏移）；**手写批注层（红笔圈线/铅笔边注——教学产品最强「物感×信息」交集）**；印章/邮戳/标签（要少一次一个）；装订固定件（回形针/订书钉只用于多件聚合）；**编号/日期/页码/档号（零素材成本的档案感，性价比最高）**；具象容器承载抽象状态（全应用最多 2 个）；唯一视角/取景框；**文字自身质感（字排是最便宜的物感，优先于任何纹理）**；声音（默认关、不做信息通道）；微动效 juice（高风险只保留翻面/落纸级）；**叙事内界面纪律（屏幕上每件物都能解释它为什么在桌上）**

理论线索：diegetic UI（收益沉浸代价可读性）；juice/polish（《Juice it or lose it》；**声音弱则物件显得弱**）；拟物化两面（收益可识别易上手；代价占空间、**视觉噪音与认知负荷**）。

### 三、8 条建议

1. **优先字排再谈纹理**（正文/边注/批注/元数据四层字排确立，白板感先消失一半——Things 3 自述）
2. **工作台三层以内的物**：桌面/当前信/边注批注；统一光源、两档阴影；禁止每卡自带风格
3. **手写批改层是最强教学×物感交集**：红笔圈线/铅笔边注/勾选划线，只在反馈时出现可开关
4. **状态装进一件实物 + Obra Dinn 规则**：只有被验证的表达才入册（「已掌握」= 日期戳/邮票落信角，不是进度条）；全应用此类容器 ≤2（一册信札/邮票册 + 一枚封印）
5. **历史不是聊天记录而是归档**：编号信札 + 索引页 + 检索（同一表达在不同信里重现 = 天然复习）
6. **动效预算制**：一次交互只允许一个「纸的物理事件」；禁粒子/抖动/弹跳/彩带/连续视差
7. **声音默认关且不做信息通道**
8. **单一房间视角纪律**：客厅/门厅/书桌三场景；任何元素都要能回答「它为什么在桌上」

**排除**（与沉静气质冲突）：游戏式 juice、3D 透视桌、厚重木纹/皮革/金属拟物、贴纸印章高密度堆叠、默认音效、无教程靠试错。

### 四、克制原则

> **一个屏幕，一次纸的物理事件；一次动，必有目的。**

三问筛选：①它在不在这个房间（diegetic）？②它装不装信息（纯装饰删）？③它是否让人更快确认当前状态？
**守恒律：纹理与动效总量守恒——新增一层材质或一个动效必须撤掉一处旧装饰。沉静产品全屏「物」符号预算 3-5 个**（信纸、印章、批注笔迹、邮票/日期戳、档案编号），其余一切保持安静。

工具：Game UI Database（1,950 款游戏/77,746 张截图，可按 UI 风格/材质/转场/Diegetic 筛选）。

## 调研E：中文文案与诗文气质

### 一、12 条手法（每条带例句）

1. **具象先行抽象后至**（李欣频「凡高阅读麦田，发现艺术躲在太阳的背后乘凉」）
2. **把功能翻译成态度**（全联「长得漂亮是本钱，把钱花得漂亮是本事」）
3. **借来的话（引文机制）**（单向历「短句+出处」；产品自己保持克制并署名）
4. **留白不把话说满**（步履不停「你不必穿得很满。」「日子渐渐变得松软。」）
5. **万物有灵**（步履不停「雨，是春天盖的邮戳。」）
6. **承认局限/反向自曝**（全联第一条自曝缺点；flomo「我们不擅长」栏）
7. **否定句的温柔**（「来全联不会让你变时尚，但是剩下来的钱，能让你把自己变时尚」）
8. **三拍节奏**（「有些穿高跟鞋走不到的路，／有些喷着香水闻不到的空气，／有些在写字楼里永远遇不到的人」）
9. **问句与对话体**
10. **语体混搭（雅言做骨架白话做血肉）**（故宫「朕亦甚想你」——**前提必须是真材料**）
11. **场景锚定**（「每天早上 8 点，给通勤路上的人」）
12. **去掉喊话式祈使**（步履不停全文无一句直接推销）

**诗文分寸（正反案）**：好——有出处署名（「山川异域，风月同天」可追溯所以站得住）；与事实同框（国宝「你来自泥土，头微微扬起」）；真材料+反差；每天一次不解释。翻车——**美而无原创（奥迪小满抄袭案）**；**伪古句**（「林深时见鹿，梦醒时见汝」改李白被伪托）；语境错位（房地产用海子）；**抒情过量（网易云→「网抑云」反噬）**。结论：①有出处就署名；②自造诗句一律现代白话不仿古；③一段话最多一处文；④**情绪必须落在具体事上——具体是矫情的唯一解药**。

### 二、书信用语小词典（14 条）

见信好（最安全开场）/展信佳·舒颜（亲和雅）/见字如面（一屏一次，已被综艺用滥）/台鉴·惠鉴（**只出现在教学示例或彩蛋**）/顺颂时祺·即颂近安（结尾，半句更好用）/专候回音（**等待回信状态区天然适配 loading**）/春寒料峭善自珍重（季节性空态，按季换=内容节奏）/春加黍谷暖恰花间（彩蛋级，主面禁）/谨白·手启（落款）/尺牍·鱼书·双鲤（需注释，谨慎）/纸短情长（**字数上限的功能性情绪化解**）/又及·再启（P.S. 雅称，零风险）/此致敬礼（偏公文，不用）。**典故**：「尺牍书疏，千里面目也」（颜之推引南朝谚）——一句话说清为什么通信能学语言，可做空厅引文（需署名）。

### 三、改写提案（雅/中/轻三档 + 推荐）

**全局策略**：`中文英文都行`现役 3 次——**全屏只保留 1 次完整直白**（placeholder，操作指令位）；**「教学发生在英文」必须至少明说一次**（功能承诺不能靠暗示）。

- **封面段**（推荐中档）：「这里只做一件事——你和一位固定笔友通信，把英语写熟。想写什么就写什么：中文、英文，或一半一半。写得不对的地方，回信里会讲给你听。」（「一半一半」比「都行」可见准确；末句把教学落实为动作）
- **who-sub**（推荐雅档）：「一位固定笔友 · 中英不拘」（「不拘」常用词语义透明 + 暗含不必拘束）
- **placeholder**（推荐中档）：「写一句吧——中文英文都行」（加语气词把说明变邀请——**减弱直白不是消除直白**）
- **空厅句**（推荐中档）：「信还没开始写——想说什么就写什么，中文英文都算数；写完这一句，就算开张。」（「算数」= 写下的中文会被当真对待被回信回应；给了极小可完成的起步动作）
- **导航三词**（推荐雅档「温故 / 信匣 / 写信」——三词两字齐整；**但需功能确证**：若柜抽装的是教学卡非信件，「信匣」名不副实改「抽屉」）。**现状问题点名：「柜抽」不是现成词（刻板随意感最重处）；「学案」学术气偏重**
- **按钮「寄出 →」**：保留，另加发送后状态行「信已寄出，等回信——可缓缓。」（按钮越短越好，仪式感交给状态行）
- **教学卡「💡 教学时刻」**（推荐「批注」家族）：「灯下批注」/「笔友的批注」——**批注把教学变成「信上被划出来的那一行」，天然解释「写错了正是客厅在听的地方」**；去 emoji；卡内「作答/跳过」→「写一句回应 / 先搁着」

### 四、语气宪法（7 条）

1. 一句一事，主句 12-22 字；30 字长句只许铺陈画面且一屏最多一句；禁同义反复
2. 破折号一屏 ≤2 处；**全站不用感叹号**（教学反馈例外且最多一个）；问号只用于真问句
3. **一屏最多一处「文」**——引文必须署名 / 古语词必须是常用词；**自造诗性一律现代白话，不仿古不写「古人云」**
4. **功能语义优先（不可牺牲）**：①中文也可以用 ②教学发生在英文 ③写错会被看见且被回应——冲突时清晰优先氛围让路
5. 禁用：喊话祈使（立即/马上/快来）、网络热词、机械对仗假古风、综艺腔、emoji 作语气
6. 对用户称「你」（不用您）；自称「客厅」（第三人称，不用我们避免客服腔）
7. 错误反馈写具体改法（「这个词换成 X 更自然」）；不写「错误/失败」标签也不写空洞安慰
**动作词表**：寄出、收起、回信、留一句、搁一搁、翻看；不夹带「提交/确认/操作成功」。

①「柜抽」需功能确证再定名；②「中英皆可」三处降调是一次实验——保留 6 人以上理解率口径（问「能不能用中文写」），任一版本低于 100% 回退中档。**所有候选句均为原创。**
