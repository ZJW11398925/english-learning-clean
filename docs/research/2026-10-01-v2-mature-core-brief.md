> 程序：`PLAN-OPI-a31b14c9-…6`（v2）｜开工裁决：`DEC-OPI-a31b14c9-…3`（用户三裁决原话在册）
> 本文件是 v2-1 内核刀的**唯一设计权威源**：排印/色彩/物化/动效/命名全部真值在此，实现不得偏离、不得自由发挥旧范式。

## 0. 一句话内核

**铁胆墨落在真纸上**：历史上真实写信用的墨（铁胆墨，冷调紫黑）× 有色度深度的纸白 × 钢笔墨蓝强调 × 朱砂只在盖印时出现。信不是皮肤，是机制——每封信有排印骨架（日期/称呼/正文/落款/又及），邮戳只落在真实事件上，封与信是两个物件，动效是纸的物理（纸先落、墨后渗）。

## 3. 排印系统（方案一「印刷本」定稿）

### 3a. 字体栈（离线、仅 Win11 系统字体；CJK 回退次序固定：西文族在前 → Songti SC → SimSun → Noto Serif CJK SC → 通用族）

```
--f-serif:      'Sitka Text', Constantia, Cambria, Georgia,
                'Palatino Linotype', 'Times New Roman',
                'Songti SC', SimSun, 'Noto Serif CJK SC', serif
--f-display:    'Sitka Display', 'Sitka Banner', Cambria, Georgia,
                Constantia, 'Times New Roman',
                'Songti SC', SimSun, 'Noto Serif CJK SC', serif
--f-hand:       KaiTi, 'Kaiti SC', STKaiti, cursive        /* 仅手迹位 */
--f-ui:         'Segoe UI Variable Text', 'Segoe UI Variable',
                'Segoe UI', DengXian, 'Microsoft YaHei UI', sans-serif
--f-mono:       Consolas, 'Cascadia Mono', ui-monospace, monospace
```

依据（本机实测）：Constantia x-height 0.453 = 宋体 0.453 **混排精确对齐**（现行 Georgia +6% 偏大）；Sitka opsz 6–27.5 大字自动切 Display 切面；DengXian 0.497 ≈ Segoe UI 0.500（雅黑 0.540 显大 8%，只作可读性吃紧处降级）。
**楷体边界**：仅 3 个用面（落款、案头日期、边注），17–24px，每屏 ≤2 行 ≤1 处；禁作正文、禁 <16px、禁 >28px。
**禁**：宋体/楷体/仿宋 font-weight:700（upem=256 单一 weight，700 = 合成粗体发糊——中文标题靠字号跳档 + 字距，或 head 档切雅黑/等线真 Bold）；数据列排雅黑/宋体数字（非等宽无 tnum——数据一律 Consolas + `font-variant-numeric: tabular-nums`）。

### 3b. 字号–行高–字距刻度（行高写整 px，4 基数；正文 = 信件正文 = 核心阅读面）

| 档 | px | 行高 | 字距 | 用面 |
|---|---|---|---|---|
| display | 34 | 42 | 中 +0.01em / 西 −0.01em | 信头/门厅题（宋体 400，禁 700） |
| title | 24 | 32 | +0.02em | 节题/页级大题 |
| head | 18 | 26 | +0.03em | 卡题/词头/批注头 |
| **body** | **17** | **32** | +0.01em | **信件正文**（1.88 为中文满框留气） |
| body-latin | 17 | 28 | 0 | 纯英文段（Sitka/Constantia） |
| small | 14.5 | 24 | +0.01em | 词卡释义/批注正文（连续阅读下限） |
| hand | 19 | 30 | +0.04em | 手迹位（KaiTi，≤2 行） |
| ui | 12.5 | 20 | +0.02em | 按钮/界面小字 |
| micro | 11.5 | 18 | 大写 +0.14em | 元信息/节名——**禁排中文整句**，只许 2–4 字标签与数字 |

**版心**：`--measure: 34em`（≈578px；中西文舒适区交集 380–580px）；窄屏 394px ≈ 23 字/行仍舒适；页边距 ≥2 行高（64px 桌面）。
**基线网格**：`--baseline: 32px`（= body 行高）；正文行高、稿纸横线周期、批注卡内文字全部锁死同值，`background-position` 对齐首行——**字必须落在线上**（现行 26px 周期 vs 25.6px 行高的逐行漂移是「假纸」最易被身体察觉处）。

### 3c. 工艺法则（10 条，逐条可执行）

1. 中文正文 ≥15px（宋/楷 upem=256 小字号断笔）；2. 禁合成粗体（见 3a）；3. 微标签统一「大写 + 0.14em 字距 + 降一档重」，不用 small-caps（Segoe UI Variable 与中文面无 smcp）；4. 信件正文旧式数字（Georgia/Constantia 默认 onum），数据列等宽 tnum；5. 中文全角「」、西文真弯引号“”、源码禁直引号，`text-spacing-trim: trim-start` 以 `CSS.supports()` 探测启用；6. 信件流段落 = 段间距 0.75em + 零缩进（西文 block 传统，回信可能纯英文）；中文文档页（设置/隐私）才 `text-indent:2em` 零段距；7. `text-wrap: pretty`（正文收孤字）/ `balance`（标题）；8. 行高只写整 px；9. 中英混排不手工插空格（正确解 = ex-height 匹配的字体，已由栈保证）；10. 正文/西文小写字距 0–0.02em（超过即「散」），加大字距只许大写微标签与 2 字中文标签。

## 4. 信件机制层物化（T1 必须 / T2 克制 / T3 死刑）

### T1 核心层（缺了就不像信）

1. **排印骨架**：每封来信 = 日期行（dateline，等宽或旧式数字）+ 称呼（salutation，不缩进）+ 正文（段间距模式）+ 结束语+落款（complimentary close + signature，楷体手迹位，齐右）+ 又及 P.S.（不缩进、弱墨）。我方回信保留撕口（人手触碰过的件才有毛边）。
2. **基线网格**（见 3b）。
3. **墨水物理**：新到信正文字色一次性 `--ink-ghost → --ink` 过渡（≈600ms，随进入动效，reduced-motion 直落终态）；墨是暖纸上的冷墨，层级靠浓淡不靠灰。
4. **封/信分物（本轮唯一「敢于加件」处）**：「在途」件与「归档」件 = 信封形（矩形 + 中央折线 + 封舌 polygon，毛边只在人手件）；「读信」= 信纸。在途信封上盖「寄出」邮戳；信档条目是信封，展开读才是信。**不做「拆信」常规演出**（一次性惊喜变日常负担 = 死刑清单）。
5. **折痕**：归档件展开时两条 1px 横线（距顶 1/3 与 2/3，opacity 3–4%），淡到初看不见、不压字。

### T2 强调层（频率规则即纪律）

- **邮戳**：双圈圆 + 内日/地字，`rotate(3–6deg)`，opacity .35–.5，`--ink-ghost` 或 `--seal`；**只落三类真实事件**——寄出（在途封）、结课（教学卡）、归档开启（信档日期戳）；同屏 ≤1 枚，多数屏 0。
- **红笔圈/批注**：现行 `.circled` 保留，色改 `--seal`；只在学习反馈存活期，回应收场即离场；一卡至多一处手迹。
- **邮票+齿孔**：仅封面/结课件，≤1 枚，不集邮不陈列。
- **火漆**：一生几次（首次进门/重要里程碑），≤1；禁裂开/融化/滴落动画。
- **档号/编号/日期**：等宽小字 + tabular-nums，只标真实编号，≤2 处/屏。
- **守恒律**：新增一层材质或一个动效必须撤掉一处旧装饰；全屏「物」符号预算 3–5 个。
- **航空信红蓝条纹**：不使用（本地单机无跨国语义；起源规格查无可信出处）。

### T3 死刑清单（贴纸化陷阱，一票否决）

手写体正文｜满屏纹理/做旧泛黄/咖啡渍｜牛皮纸+麻绳+胶带+便利贴｜蜡封拆封转场常规化｜纸屑/粒子/彩带/抖动｜emoji 语气｜彩色徽章胶囊标签｜邮戳满屏盖/邮票墙｜方格纸作正文底｜3D 透视桌面/翻页 flipbook/视差｜发光/泛光/毛玻璃/大圆角卡片｜非墨色同源阴影｜常驻循环/呼吸灯/脉动｜打字机动画用于长文｜音效。

## 5. 动效手感（「纸先落、墨后渗」）

| 事件 | 进入 | 退出 |
|---|---|---|
| 新信到达 | 280ms `cubic-bezier(.16,1,.3,1)` translateY(8px)；**opacity 360ms（≈1.3×慢于 transform，同曲线）** | — |
| 我的信寄出 | 盖戳 120ms `cubic-bezier(.4,0,.2,1)` scale(.96→1)（全应用唯一 overshoot 许可）；信体 240ms 入场 + 2px 下沉「落桌」 | 在途角标随信落地即摘 |
| 教学卡展开 | 260ms `cubic-bezier(.05,.7,.1,1)` + translateY(8px) | 200ms `cubic-bezier(.3,0,1,1)` |
| 回复流入多行 | 每行 140ms fade，stagger 40ms，**总封顶 320ms**（只前 8 项） | — |
| hover/触压 | 100ms 色/下划线/雾 .08；active translateY(1px) | 释手 100ms 归位 |
| 回执/系统行 | 100ms 加速 `cubic-bezier(.3,0,1,1)` + 4px「落下即止」 | 同 100ms |

**纸的物理法则**：位移 4–12px 封顶；无弹性回弹（唯一 overshoot = 盖印收束）；进入减速长尾/退出加速收势/禁 linear；transform 与 opacity 拆开且 **opacity 恒慢于 transform**（反向 = 虚像浮现 = 数字语汇）；大件 ≤320ms、微交互 ~100ms（NN/g 100ms 内必须有可见反馈）；纸不发光；阴影不做动画（用垫纸层 opacity 换）；**一屏一次纸事件；零常驻循环**（现行 `state-breathe` 1.6s 呼吸点**删除**，改静态弱化行）。
**降级双面**：CSS 0.01ms 技巧保 animationend + `matchMedia` change 停 rAF；信息不得只有动画一个载体。
**基线**：NN/g 0.1/1/10s 三阈值；M1 桌面 150–200ms、>400ms 恐过慢；Carbon fast-01 70 / fast-02 110 / moderate-02 240ms。

## 6. 形态法则（承 F-1R 用户否决条款，语义不变）

零卡片、零气泡、零底栏页签、零大圆角面板、零青绿——分层靠上下发丝线、留白与三级墨色；动作一律是墨蓝下划线文字链接；纸叠偏移阴影两级沿用（墨色同源）。**v2 增补**：圆角半径全面收窄一档（信纸物件 ≤2px，仅邮票/邮戳允许圆形）；一切「面板感」容器退化为「纸面 + 发丝线」。
